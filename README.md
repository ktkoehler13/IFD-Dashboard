# Ithaca Fire Department by the Numbers (draft)

Rough draft dashboard for internal review. Data as of October 17, 2026. Not for distribution.

`index.html` is a single self-contained page: all figures, the department patch and the
chart code are built in (charts load the d3 library from cdnjs). Open it in any browser,
or view it through GitHub Pages if enabled for this repository.

Figures are summaries computed from Ithaca Fire Department CAD incident exports. No names,
addresses or incident numbers are included.

To update: replace `index.html` with a newly generated version and commit.
